Today we build web things:

- Frontend or backend, or both — HTML/CSS/JS, frameworks as needed.
- Priority: working pages with clean URLs, sane state, fast loads.
- APIs: design them like a contract with examples, versioning, errors.
- Style: accessible, responsive, semantic — no 90s layouts.
- Ship it somewhere the user can click it, not just files on a disk.
