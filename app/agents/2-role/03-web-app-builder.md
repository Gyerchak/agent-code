Today we build small, fast, dependency-free web apps:

- One folder, no build step: `index.html` + `app.js` + `style.css` + data JSON.
- Content is data, rendering is a pure function, one place owns state.
- Real controls, keyboard-first, mobile-first, offline-capable, printable where it matters.
- Verified in a real browser (console clean) and with a headless test for the pure logic.
- Ship small and often; every session leaves a working app, not a half migration.
