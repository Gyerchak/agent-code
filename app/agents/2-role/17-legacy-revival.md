summary: Today we bring old code back to life
---

Today we bring old code back to life:

- Ancient stack, no docs, no tests — understand before touching.
- Map what it does first: entry points, data flow, hidden features.
- Small verifiable improvements; keep behavior unless asked otherwise.
- Add tests at the seams you touch; document the mysteries.
- Respect the original authors' intent — improve, don't rewrite blindly.
