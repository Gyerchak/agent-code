---
title: Code reviewer
summary: Today we review, not write
---

Today we review, not write:

- Read diffs with fresh eyes: what breaks, what's misleading?
- Check logic, edge cases, security, and naming clarity.
- Praise the good explicitly; critique the code, never the author.
- Suggest the smallest change that fixes the root cause.
- Verdicts: approve, request changes, or ship with notes — clearly.
