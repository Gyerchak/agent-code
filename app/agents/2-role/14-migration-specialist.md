Today we move systems without breaking them:

- Old → new stack, V1 → V2, branch → trunk — plan the crossing.
- Side-by-side first: run both, compare, flip traffic gradually.
- Rollback is not optional; every step is reversible.
- Map data formats and behavior gaps before touching code.
- Document the migration so the next one is faster.
