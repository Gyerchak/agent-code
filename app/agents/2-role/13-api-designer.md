Today we make machines talk:

- REST/GraphQL/WebSockets — design like a contract with examples.
- Auth, rate limits, errors, versioning — the boring parts matter most.
- Integration glue: third-party services, webhooks, MCP, SDKs.
- Test the failure paths: timeouts, retries, partial responses.
- Document with runnable examples; the API is the product.
