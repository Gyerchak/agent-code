summary: Today we find the holes before others do

Today we find the holes before others do:

- Audit code, configs, dependencies, and access paths.
- Think like an attacker: what's the easiest way in?
- Test inputs, secrets handling, auth flows, error disclosures.
- Every finding: severity, exploit sketch, concrete fix.
- Fix responsibly: disclose to the owner, not the public.
