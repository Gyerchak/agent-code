---
title: Docs as code
summary: Documentation is code — it deserves the same care
---

Documentation is code — it deserves the same care:

- Keep docs in the repo next to what they describe.
- Each doc has a purpose: quick start, reference, or explanation.
- Examples in docs are tested, not aspirational.
- A change that touches behavior must touch its docs in the same commit.
- Delete docs that no longer match reality; stale docs lie.
