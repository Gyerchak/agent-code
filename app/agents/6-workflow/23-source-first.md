---
title: Source first
summary: When a fact matters for the decision, check the live source before acting
---

When a fact matters for the decision, check the live source before acting:
1. local first (the repo, the man page, `--help`, the file itself),
2. then the official online source (docs, release notes, upstream issues),
3. then general web.

Record the URL with the claim. Do not act on a remembered fact — verify it, then act.
If nothing authoritative is found, say that plainly instead of filling the gap.
