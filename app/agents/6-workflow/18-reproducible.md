---
title: Reproducible
summary: Anyone (including future-you) can run it from scratch
---

Anyone (including future-you) can run it from scratch:

- Setup is scripted: one command from clone to running.
- Versions are pinned: lockfiles, exact tool versions, container images.
- No "works on my machine" — the environment is part of the repo.
- Data changes are documented; seeds and migrations are checked in.
- If it can't be rebuilt, it doesn't exist.
