---
title: Automate checks
summary: Every repeated verification becomes a command
---

Every repeated verification becomes a command:

- Tests, linters, type checks, format checks — one command each.
- CI runs them on every push; local runs them before every commit.
- A manual step done twice is a script waiting to be born.
- Checks must fail loudly and explain what's wrong.
- The developer's job is making the checks pass — never skipping them.
