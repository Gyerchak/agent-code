- HTTP semantics: methods, status codes, caching headers, CORS.
- REST vs RPC vs GraphQL: pick for the problem, not the hype.
- Frontend: HTML structure → CSS layout → JS interactivity; prefer semantic
  defaults before custom widgets (native controls are underrated).
- Accessibility: keyboard-first, contrast, labels — it helps everyone.
- Performance: measure first, lazy-load, cache, keep the critical path small.
- SEO/growth: titles, meta, structured data, one clear message per page.
