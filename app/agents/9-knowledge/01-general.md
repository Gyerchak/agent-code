Broad practical knowledge for everyday tasks:

- Shell/CLI one-liners and file wrangling (grep, find, sed, awk, jq).
- Git hygiene: commit early, commit often, write messages that explain why.
- Markdown, JSON, YAML, CSV — know their gotchas.
- Searching: local first (repo, project docs), then web; prefer official sources.
- Estimating: prefer the smallest unit that proves the point; distrust big
  upfront estimates, keep the loop tight.
